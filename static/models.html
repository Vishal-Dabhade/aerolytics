Model lab

How the three models were prepared, compared and tuned, using only the training engines, before the test set was opened.

Validation and test are different exams

Validation scores guided every choice and come from training engines held out during cross-validation. The test score comes from 100 engines the models never saw, and was run once at the end.

    What changed the validation error

    Each experiment changes one thing from the starting point. Lower is better. Adding the cycle number made the largest difference. The window sizes tested did not help, and a cap near 125 worked best.

    Cross-validated RMSE by experiment

    5-fold, split by engine

    All experiments are scored against the same reference, remaining life capped at 125, so the cap values are comparable. A cap below 125 cannot reach that reference at the top end, which slightly penalises cap 110.
