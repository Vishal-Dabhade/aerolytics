Know the engine before it fails.

Every engine wears down a little on every flight. AEROLYTICS reads a turbofan's sensor data and estimates how many flight cycles it has left, so maintenance can be planned before a fault becomes a failure.

How the estimate is made honest

  1. Prepare the data

    Eight columns that never change are dropped. The rest are scaled, and each sensor gets a three-cycle rolling average.

  2. Cap the target at 125

    While an engine is healthy its sensors barely move, so training only asks the models to tell apart the last 125 cycles of life.

  3. Validate by engine

    Cross-validation holds out whole engines, so the models never see part of an engine they are scored on.

  4. Test once

    The final score uses 100 unseen engines and their actual remaining life, with the cap applied only to training.
